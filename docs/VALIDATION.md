## 실행 범위

```bash

uv run python -m tools.audit_results
```

## 매출 정정 검증

원문 표 45개 중 41개를 코드로 읽었고, 지원하지 않는 4개는 기존 추출값을 유지했다. C03·C07·C08·C18·C39의 매출을 정정했다. 다시 정정 도구를 실행하면 변경 대상은 0곳이다.

망고부스트 원문 표는 `2023 국내 - / 2024 국내 21,818천원 / 2023 해외 $100,000 / 2024 해외 -`다. 2024년 국내 매출은 21,818,000원, 약 0.2억 원으로 확인됐다.

- E2: 2점, **확인불가 아님**. 사유는 최근 연도 매출 1억 원 미만이다.
- Q7: **PARTIAL**, 숫자 규칙으로 판정됐다.
- 보고서 리스크에도 작은 매출 규모와 최신·반복 매출 확인 필요를 적었다.
- 현재 미확인 점수 항목은 B1(목표 시장 규모·성장률), C3(핵심 성능 지표), D2(경쟁사 대비 차별성) 세 개다. E2는 포함하지 않는다.

216개 테스트가 통과했다. 경고 5개는 PyMuPDF의 SWIG 관련 DeprecationWarning이다. 점수·평균·판정·순위·유효 근거 ID, Q7과 E2/E3의 숫자 일치, 실행 완료와 PDF 5쪽 제한 점검을 통과했다.

실행 오류가 없다는 사실은 모든 서술과 외부 자료가 사실임을 보증하지 않는다. 직접 목표 시장 수치, 실측 성능과 동일 조건의 경쟁 비교는 여전히 확인하지 못했고 보고서에도 한계를 남겼다. 원문 기업 자료는 디렉토리북 작성 시점의 기록이다.
